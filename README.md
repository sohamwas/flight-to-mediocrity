# Flight to Mediocrity — interactive demo

Play the selector in **MatchMarket**: hire one of three LLM candidate agents whose true skill is hidden, with and without an audited record, and compare yourself with four open models.

**Live:** https://sohamwas.github.io/flight-to-mediocrity/

Companion to *Flight to Mediocrity: Why LLM Agent Selectors Under-Hire Experts When Quality Claims Are Unverified* (Soham Wasmatkar, REALM Workshop @ EMNLP 2026). Every round, vote and quotation on the page comes from the paper's logged experiment data.
